# PaymentShield

A security-focused payment intelligence platform built with Stripe, FastAPI, React, and PostgreSQL.

## Features

- Stripe Checkout Integration
- Payment Event Monitoring
- Fraud Detection & Risk Scoring
- Alert Management
- Transaction Investigation Dashboard
- Audit Logging
- Webhook Signature Verification

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- FastAPI
- SQLAlchemy

### Database
- PostgreSQL

### Payments
- Stripe API
- Stripe Webhooks
